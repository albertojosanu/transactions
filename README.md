# SkyproWallet

Приложение SkyproWallet предполагает возможность просмотра, добавления и удаления записей о покупках пользователя

## Разворачивание

Чтобы развернуть приложение локально, необходимо 
- скачать проект и переместить папку с файлами в удобное место,
- открыть IDE и открыть проект, указав место раположения приложения,
- проверить наличие установленных пакетов (при отсутствии выполнить их инсталляцию):
node -v
npm -v
- установить используемые зависимости
npm install
- запустить live сервер
npm run dev
